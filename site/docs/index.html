How to read the labels

A document is labelled by what it is, and each label is checked against the file: a document that grows past its label fails a test until the label is changed.

  • Reference long, to searchEvery field and every message. Hundreds of lines; meant to be searched, not read from the top.
  • Guide read in orderOne job from start to end: deploying it, running it, licensing it.
  • Short a page or twoA summary or a policy; read it whole.
  • Log what changedA record by version, newest first.

Each title opens the document on GitHub. The path under it is where the file is in the repository, if you would rather read it in a copy of your own.
