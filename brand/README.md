# The Ordane brand files

The logo, the mark, the icons and the social card. How to use them, and what the name and voice are, is in
[docs/brand.md](../docs/brand.md).

Every `.svg`, `social-card.html` and `tokens.css` here is generated by one script from one description of the mark, so
no variant can be edited by hand and left disagreeing with the others:

```bash
npm run brand:build      # rewrites these files
npm run brand:check      # exits 1 if one differs from what the script writes (a test runs the same check)
CHROME=/path/to/chrome node scripts/build-brand.mjs --png     # also renders the three PNGs with headless Chrome
```

The PNGs (`apple-touch-icon.png`, `icon-512.png`, `social-card.png`) are rendered from the SVGs and the card's HTML. They
are not byte-reproducible across Chrome versions, so they are not checked for drift; a test checks that they exist and
have the sizes the pages promise.

To change the tagline on the card, the colours or the geometry, edit `scripts/build-brand.mjs`, rebuild with `--png`, and
copy what the site uses into `site/assets/` (`favicon.svg`, `apple-touch-icon.png`, `social-card.png`): a test keeps
those copies equal to these files. The dashboard and the site draw the logo inline; the same test checks that their
paths match `ordane-logo.svg`.
