## 1. Change Summary

Restructure the Designer page and shared shell to answer five questions within ~2 seconds:
what am I building, is it running, is it valid, what needs my attention, and what happens
when I press the primary button. Information architecture + interaction discoverability
change only: no server, persistence, protocol, or event-log changes. All existing actions,
hotkeys, draft persistence, and save semantics are preserved.

## 2. Scope

In scope:
- Shared shell: top-bar status/action separation, needs-you prominence, decide label,
  sidebar section/hotkey presentation (review points 2, 3, 10, 11, 12, 13, 19).
- Designer: header/state summary, draft-vs-runtime indicator, bottom action hierarchy,
  graph affordances, inspector disclosure, permission grouping, visual flattening,
  typography, responsive layout, focus mode, command palette (points 1, 4–9, 14–18, 20–24).
- Light and dark themes both remain supported (`isLight`/`toggleTheme`, shell.tsx:114-120,
  render site :266).

Out of scope (deferred non-goals):
- Revision numbers/version history (user decision; no server support).
- Hot-apply of saved config to a running mesh: save stays a file write; restart-to-apply
  is made explicit instead.
- Automated UI/component test harness (none exists; §12).
- Backend/API changes of any kind; new UI/runtime dependencies.

## 6. Impact Analysis

- Affected: `apps/mesh-dashboard/src/**` only. Shared shell changes affect every view —
  regression-sensitive; phase order and the §12 checklist mitigate.
- Unaffected: server, packages, protocol/schemas, event log, persistence, CLI.
- No API, DB, migration, or messaging surface.
- Observability: N/A (client SPA); existing toasts/banners remain the feedback channel.
- Security: N/A in a new sense — no new network surface, no secrets; palette exposes only
  existing client actions; destructive actions keep confirm (reset) or undo (wire cut).
- Behaviour preserved: INV-DSG-001..008.

## 7. Proposed Design (workstreams)

Design decisions:
- DES-DSG-001: No revisions; SourceState derives from existing `dirty`/`diff`/`runningRaw`
  (user decision).
- DES-DSG-002: Save stays file-write; copy says so. Do NOT label "Apply changes"
  (verified false, server index.ts:1136). Primary label "Save mesh" / "Save running config"
  / "Save copy" with persistent "writes mesh.yaml · restart to apply".
- DES-DSG-003: Shell included (user decision).
- DES-DSG-004: Hotkey numbers are restyled with the existing `<kbd>` chip, never removed
  (INV-DSG-002).
- DES-DSG-005: Edge cut = click-to-select edge + explicit Cut + Delete key, with input
  guards; no modal confirm because cut is undoable (Designer.tsx:354). Hover-only `×`
  removed.
- DES-DSG-006: Focus mode hides Designer-owned regions with CSS (no unmount) and asks shell
  to collapse the sidebar through one boolean seam; verdict stays visible.
- DES-DSG-007: Responsive uses the EXISTING breakpoint scale (1240 Designer / 800 shell);
  crew rail = CSS disclosure; inspector = scoped right drawer variant. The global modal
  drawer stack (shell.tsx:313-321, focus trap + scrim) is NOT reused for persistent rails.
- DES-DSG-008: Command palette = global navigation commands + Designer-scoped commands
  registered while mounted via a small `src/commands.ts` registry. This is the one new
  seam; it is flagged for explicit user permission at checkpoint 2 (panel finding).

## 9. Concurrency and Consistency

Not applicable in the distributed sense. Local consistencies that matter:
- Draft is a module singleton + localStorage; multi-tab divergence is handled by the
  existing stale-running guard — keep it.
- Key routing is the real concurrency risk: shell.tsx:121-151 (bubble), Tab trap :212-242,
  drawer Esc :132-135, Designer Esc :164, Topology Esc :44, plus new palette/focus. WS10
  must define ONE dispatch order (palette → focus → drawer stack → local) so a single Esc
  does not close several layers at once.
- `diff` must recompute after `doSave` mutates `draft.runningRaw` (:446) — explicit running
  revision counter.

## 10. Failure Modes

- Save overwrite/stale running file between validate and save: unchanged; keep ReviewCard
  warning (chrome.tsx:121).
- localStorage unavailable/quota: existing handling not inspected (NON-BLOCKING UNKNOWN);
  SourceState must degrade safely.
- Diff stale after save: mitigated by the revision counter; manual check in §12.
- Backspace-to-cut while typing: mitigated by input guards; manual check.
- Palette command on a stale selection (agent deleted): resolve ids at invocation, no-op
  with a toast.
- Focus mode left active across view switch: clear on view change (Shell does not unmount).
- Breakpoint overlap (800–1240 undefined behavior): WS8 owns reconciliation.
